# Packet Tracer Network Engineering Portfolio

Welcome to my Packet Tracer Network Engineering Portfolio.

This repository showcases my hands-on networking projects and laboratory exercises created using Cisco Packet Tracer. It serves as a collection of practical network implementations that demonstrate my understanding of networking concepts and Cisco device configuration.

## Repository Contents

Each project is organized in its own folder and may include:

- Project documentation
- Network topology diagrams
- Cisco device configuration files
- Packet Tracer (.pkt) files
- Screenshots and validation results

## Skills Demonstrated

- Network Design
- IP Addressing and Subnetting
- VLAN Configuration
- Inter-VLAN Routing
- Static Routing
- Switch Configuration
- Router Configuration
- Network Troubleshooting
- Cisco IOS CLI

## Tools

- Cisco Packet Tracer
- Cisco IOS CLI
